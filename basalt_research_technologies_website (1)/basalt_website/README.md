# Basalt Research & Technologies website

A responsive, static company website built from plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and SEO metadata
- `styles.css` — layout, responsive styles, colours, geometric hero illustration
- `script.js` — mobile navigation and current year
- `assets/basalt-logo.png` — your supplied Basalt logo, with transparent background

## Preview locally
Open `index.html` in a browser. For a local server, run:
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Publish
- **GitHub Pages:** create a repository, upload these three files to the root, then enable Pages in repository Settings.
- **Vercel:** import the repository and deploy as a static site. No build command is needed; set the output directory to `.` if prompted.
- **Hostinger:** upload the three website files to the site's `public_html` directory.

## Before publishing
1. The contact email is set to `contact@basaltresearch.in`.
2. Confirm whether the public brand should be “Basalt Research & Technologies” or a registered legal entity name.
3. Add the real company domain and any approved LinkedIn/GitHub links.
4. Confirm that the leadership descriptions and investment disclaimer match the company's actual operations and applicable requirements.
5. The current site intentionally does not claim regulatory registration, performance results, client names, or audited track records.
